# Contributing to TWOZERO

Most help comes as bug reports and ideas. Both are welcome.

## Questions

Ask in [Discord](https://discord.gg/zyTzVdAaSV). Issues are for bugs and feature requests.

## Report a bug

1. Update the plugin: **Settings > Check updates**. The bug may already be fixed.
2. Search the open issues. If yours is there, add your details to it.
3. Open an issue with the bug form: your TouchDesigner build, OS, plugin version and agent.

You can also report from the agent chat: type `twozero bug report`.

Security problems go through private reporting, not issues. See [SECURITY.md](SECURITY.md).

## Suggest a feature

Open an issue with the feature form. Start with what you want to do in TouchDesigner and what gets in the way today. The task tells us more than a button you have in mind.

## Pull requests

Small fixes to docs and code are welcome. For anything bigger, open an issue first, so we agree on the approach before you spend time on it.

- One change per pull request.
- Say what changed, why, and how you checked it.
- Keep secrets, tokens and local paths out of the code.
- Write in English, in plain words.

A maintainer reviews every pull request. Your contribution is released under the license of the repository you contribute to.
