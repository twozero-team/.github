# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately on GitHub: in the repository, open **Security > Report a vulnerability** and describe what you found. Only the TWOZERO team sees the report.

Can't use GitHub? Email hello@twozero.ai with "Security" in the subject.

Include:

- what is affected: the plugin and its MCP server, an extension, twozero.ai or app.twozero.ai
- versions: the plugin version from Settings, your TouchDesigner build, your OS
- steps to reproduce, or a proof of concept
- what an attacker could do with it

## What happens next

We reply in the report, fix the problem and publish an advisory when the fix ships. You are credited in the advisory unless you ask us not to.

## Supported versions

We fix security problems in the latest release of the plugin and of each extension. Update before you report: **Settings > Check updates**.

## Scope

- the TWOZERO plugin for TouchDesigner and its MCP server
- the code in TWOZERO's public repositories
- twozero.ai and app.twozero.ai
